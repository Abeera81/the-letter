# Review Checklist — run before declaring the build finished

## The differentiator
- [ ] Span Gate exists, is under ~100 lines, is well-commented, and is easy to find
- [ ] Dropped claims are visible in the UI, not just in a log
- [ ] Gemini call #2 provably never receives the source letter (test passes)
- [ ] Deliberately corrupting a claim's evidence causes a visible drop

## Product rules
- [ ] No output anywhere states or implies eligibility
- [ ] No output recommends appealing or any legal strategy
- [ ] Fixed footer appears on every result, generated by code not by a model
- [ ] AI failure fails closed — never a partial explanation
- [ ] Hostile fixture is explained, not obeyed
- [ ] No letter text is written to disk, logged, or persisted — including in error paths

## Accessibility
- [ ] Full keyboard run-through completed, visible focus throughout
- [ ] Usable at 360px width
- [ ] Usable at 200% zoom
- [ ] All contrast meets WCAG AA
- [ ] Touch targets ≥48px
- [ ] Every control has an accessible name
- [ ] `prefers-reduced-motion` respected
- [ ] Body text ≥18px

## Works
- [ ] All four fixtures run end to end
- [ ] Audio plays on a real phone, including iOS Safari
- [ ] Urdu renders RTL correctly and speaks intelligibly
- [ ] Slow replay works in one tap
- [ ] Print card produces one clean page
- [ ] Every error state names what happened and what to do
- [ ] Empty state offers a tappable example letter
- [ ] No dead buttons, no placeholder text, no lorem ipsum, no console errors

## Ship
- [ ] `npm run build` passes clean
- [ ] `npm run test` passes
- [ ] Keys are server-side only; nothing secret in the client bundle
- [ ] Rate limiting on both API routes
- [ ] Deployed URL works from a fresh browser with no cache
- [ ] README explains the Span Gate and credits any borrowed code
- [ ] Any post-deadline commits noted in the README
- [ ] Demo video recorded and rewatched once
